# Диск-Мастер — обзор возможностей

Десктопное приложение для Windows 11: контроль места на дисках, очистка, поиск
«пожирателей» места, управление программами и живой мониторинг системы
с виджетом на рабочем столе. Интерфейс — окно приложения, фоновая работа — иконка в трее.

## Установка

Два варианта из папки `output/`:

| Файл | Что это |
|---|---|
| `DiskMaster_1.1.0_x64-setup.exe` | Установщик: ярлык на рабочем столе и в меню «Пуск», выбор папки установки, удаление |
| `DiskMaster-portable-1.1.0/` | Портативная версия: распакуйте папку и запустите `DiskMaster.exe`, установка не нужна |

Приложение открывается обычным окном, сворачивается в трей и продолжает работать в фоне.
Закрытие окна (крестик) тоже сворачивает в трей — полный выход через меню иконки в трее.
Оба варианта работают без прав администратора; системные папки (Temp Windows, кэш обновлений,
Prefetch, логи) доступны только при запуске от имени администратора.

Запуск занимает **около 0,25 секунды** до готового интерфейса, приложение занимает
**25–80 МБ памяти**. В шапке есть переключатель **тёмной и светлой темы** — выбор запоминается
между запусками.

## Как включить виджет

1. Откройте раздел **Виджет** в левом меню.
2. Нажмите **«Запустить виджет»** — панель появится в **правом верхнем углу** экрана,
   рядом с часами (по умолчанию 320×210).
3. Перетаскивайте её левой кнопкой мыши за любое место, размер меняйте, потянув за край
   панели. Высота подстраивается под набор метрик, пустого места внизу нет.
   Позиция и размер запоминаются автоматически.
4. Не видно панели? Нажмите **«На экран»** — виджет вернётся в угол. Это помогает, если
   панель осталась на отключённом мониторе или уехала за границу экрана.
5. Правый клик по виджету — меню: обновить, скрыть на 10 минут, свернуть в трей, закрыть.
   Двойной клик — сохранить позицию.

Панель также управляется из меню иконки в трее: «Показать/скрыть виджет на рабочем столе».

**Три режима окон** (раздел «Поведение окон»):
- **Под окнами** — виджет лежит над обоями и прячется за развёрнутыми окнами (не мешает работе);
- **Обычный** — как обычное окно, участвует в Alt+Tab;
- **Поверх всех** — всегда на виду.

Если выбран «Под окнами», виджет может быть не виден при развёрнутых приложениях —
это ожидаемо: сверните окна или смените режим на «Обычный».

## Разделы

| Раздел | Что делает |
|---|---|
| **Обзор** | Диски с заполнением, CPU/RAM/аптайм, статус прав администратора |
| **Мониторинг** | Живые графики CPU (общий + 16 ядер), памяти, диска и сети; спарклайны; топ-12 процессов с завершением |
| **История места** | Снимок каждые 30 минут: график занятого места по каждому диску, тренд «+ГБ в день» |
| **Очистка** | 12 категорий мусора: Temp, кэш 5 браузеров, Windows Update, Delivery Optimization, Prefetch, дампы, thumbcache, INetCache, D3DSCache, логи, корзина |
| **Анализ диска** | Дерево как ncdu: раскрывайте папки стрелкой, видно размер каждой подпапки; удаление файла или отдельной подпапки с подтверждением (Del или правый клик) |
| **Большие файлы** | Поиск файлов от 100 МБ до 1 ГБ, удаление в корзину, «показать в проводнике» |
| **Дубликаты** | Группировка по размеру + SHA-256, «оставить первый», удаление копий в корзину |
| **Программы** | 101 программа из реестра с путём установки (клик открывает папку), поиск, сортировка, удаление через штатный установщик (в т.ч. тихое) |
| **Обновления** | winget: список доступных обновлений и обновление по одному или всех сразу |
| **Автозагрузка** | Реестр Run (HKCU/HKLM/x86), папка Startup, задачи планировщика: включение/отключение/удаление |
| **Расписание** | Автоочистка через Планировщик Windows: ежедневно / по дням / раз в месяц / при входе, выбор категорий, журнал запусков, «Запустить сейчас» |
| **Виджет** | Прозрачная панель на рабочем столе: горизонтальные полосы индикаторов, перетаскивание, растягивание за края, прозрачность, акцент, набор метрик, режим z-order, клики сквозь, автозапуск. Настройки сохраняются между запусками |

## Технические детали

- **Приложение** — Tauri 2: Rust-ядро + системный **WebView2** вместо встроенного Chromium.
  Интерфейс собирается Vite и вшивается в исполняемый файл. Локального HTTP-сервера и открытого
  порта нет — интерфейс общается с ядром через IPC, поэтому снаружи к приложению подключиться нельзя.
  Установщик и портативная версия весят около 10 МБ, запуск — доли секунды, память — десятки мегабайт.
- **Трей** — меню с пунктами: открыть, показать/скрыть виджет, снимок свободного места,
  автозапуск при входе, выход. Сворачивание и закрытие окна уводят приложение в трей.
- **Метрики** — один долгоживущий PowerShell-процесс, читающий
  `Win32_PerfFormattedData_PerfOS_Processor`, `Win32_PerfRawData_PerfDisk_PhysicalDisk`
  и `Win32_PerfRawData_Tcpip_NetworkInterface`; история хранится в памяти (240 точек).
  Счётчики локализованы в русской Windows, поэтому `typeperf`/`Get-Counter` не используются.
- **Виджет** — отдельный WPF-процесс (XAML через PowerShell), окно без рамки с `AllowsTransparency`,
  `WS_EX_TOOLWINDOW`, `HWND_BOTTOM` для режима «под окнами», `WS_EX_TRANSPARENT` для кликов сквозь,
  иконка в трее, сохранение позиции и размера.
- **Удаление** — файлы в корзину через `Microsoft.VisualBasic.FileIO` (`DeleteFile`/`DeleteDirectory`),
  папки — так же; корневые и системные пути, а также всё, чего не было в результатах сканирования,
  удалить нельзя.
- **Расписание** — задание `\DiskMaster\DiskMasterAutoClean`, запускает сам exe с флагом
  `--run-scheduled-clean` (без окна); отчёт каждого запуска пишется в журнал.
- **Обновления** — приложение проверяет подписанный `latest.json` в GitHub Releases и предлагает
  обновление; установка начинается только по кнопке. Подпись проверяется ключом, вшитым в приложение.
- **Данные** — `%LOCALAPPDATA%\DiskMaster` для установленной версии; в портативной — папка
  `disk-master-data` рядом с exe (история, настройки виджета, журнал расписания).

## Проверено на реальной системе

- Запуск: 225 мс до окна, 21–29 МБ памяти сразу после старта (Windows 11, Ryzen 7 5800U)
- Портативная сборка: один exe 9,8 МБ, данные создаются рядом с ним, установка не нужна
- Светлая тема: контраст текста от 4,6:1 во всех 12 разделах (норма WCAG AA — 4,5:1)
- Виджет: полосы индикаторов совпадают со значениями, запуск и остановка из окна и из трея
- Окно открывается с заголовком «Диск-Мастер», 12 разделов в меню, стили и графики отрисованы
- Сворачивание в трей: окно скрывается, процесс живёт, восстанавливается обратно, позиция сохраняется
- Повторный запуск не создаёт второй экземпляр, а показывает уже открытое окно
- Скан: 6,3 ГБ мусора, 195 640 файлов; категории, права и прогресс отображаются корректно
- Анализ профиля: 5,1 ГБ / 23 824 файла, дерево с размерами подпапок
- Дубликаты: 547 групп (593 МБ лишнего) на 305 830 файлах за 31 с
- 101 программа с путями установки, 18 доступных обновлений winget, 7 записей автозагрузки
- История места: снимки при запуске и каждые 30 минут, тренд «+МБ в день»
